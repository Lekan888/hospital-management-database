# Hospital Management Database

## 📌 Project Overview

A relational database management system built with MySQL to manage
hospital operations including patients, doctors, nurses, departments,
appointments, admissions, medications, prescriptions, medical tests,
and payments.

## 🛠️ Technologies Used

- MySQL
- SQL
- MySQL Workbench

- Foreign Keys
- AUTO_INCREMENT
- NOT NULL constraints
- UNIQUE constraints
- CHECK constraints
- DEFAULT values
- One-to-Many Relationships
- Many-to-Many Relationships
- JOINs
- Aggregate Functions
- GROUP BY
- HAVING
- Subqueries
- Views
- Stored Procedures

- Audit Logging
- Transactions

## ⚡ Automated Features

### Medication Stock Trigger
Automatically decreases medication stock when a prescription is created.

### Room Occupancy Trigger
Automatically changes a room's status to `Occupied` when a patient is admitted.

### Room Availability Trigger
Automatically changes a room's status to `Available` when a patient is discharged.

### Audit Logging
Records important database actions including INSERT, UPDATE, and DELETE operations.
